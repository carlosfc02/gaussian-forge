GaussianForge is an object-centric reconstruction pipeline. It selects one object, propagates SAM 2 masks through the source video, estimates cameras with COLMAP, trains a 3D Gaussian Splatting model and can refine that model into SuGaR mesh outputs.

} @if (isVisible('basic-dashboard')) {

Dashboard

The dashboard lists every scene, its current stage, estimated completion and generated asset count. Search accepts scene names, stages and statuses.

Project states

Active states represent the currently running stage. Ready states mean the corresponding artifact exists. Error and Canceled require user attention before another run.

} @if (isVisible('basic-create-project')) {

Scene name

Use at least three letters, numbers, underscores or hyphens. The name organizes videos, masks, jobs, datasets, logs and models.

Source video

Upload MP4, MKV, MOV or AVI. Stable lighting, a visible object and smooth camera movement improve every later stage.

} @if (isVisible('basic-run-pipeline')) {

Start

Select a preset and press Run pipeline. The backend starts the shared pipeline script in the background and the page begins polling status and logs.

Cancel

Cancel pipeline terminates the active run and marks it as canceled. Existing completed artifacts are kept and can be reused by a later advanced run.

} @if (isVisible('basic-monitor-results')) {

Metrics

The latest available reports summarize COLMAP, 3DGS and SuGaR evaluation output.

Generated assets

Local viewers

Open the trained 3DGS model or latest refined SuGaR PLY on the backend workstation.
